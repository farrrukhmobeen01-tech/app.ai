## 📌 1. Project Overview

University students face a demanding academic environment where coursework, exams, team projects, career planning, and university policies compete for time and attention. **CampusFlow AI** was created as an all-in-one smart workspace specifically tailored to university and college students.

Rather than fragmenting student workflows across multiple disjointed tools, CampusFlow AI integrates intelligent academic tracking with embedded AI assistants powered by Google's Gemini API. From breaking down complex lecture notes and automatically scheduling study blocks to evaluating academic risk and generating step-by-step career roadmaps, CampusFlow AI serves as an intelligent co-pilot throughout a student's entire degree journey.

---

## 🎯 2. The Real Problem

> **The Problem**
>
> Students struggle with assignments, quizzes, exams, deadlines, study planning, career preparation, and campus resources because everything is spread across multiple apps. This creates information overload, missed deadlines, poor planning, academic stress, and difficulty getting personalized help.

> **CampusFlow AI solves this by...**
>
> Bringing all these needs into one intelligent, student-focused platform. It unites centralized academic data with context-aware Gemini AI models to provide proactive risk tracking, automated study scheduling, interactive learning aids, and career guidance tailored to actual course loads and goals.

### 🔍 The Challenge in Detail
University students routinely manage:
- **Multiple courses** with distinct syllabi and grade weightings
- **Overlapping assignments**, quizzes, midterms, and final exams
- **Group projects** requiring task division and milestone tracking
- **Career development**, resume building, and skill mapping
- **Administrative campus procedures** and institutional communications

When these tasks are managed across separate calendars, note-taking apps, spreadsheets, and generic chat assistants, students experience:
1. **Information Overload & Fragmentation:** Key dates and study materials get buried across multiple platforms.
2. **Missed Deadlines & Reactive Studying:** Without unified scheduling and risk tracking, deadline conflicts are discovered too late.
3. **Academic Stress & Burnout:** Unstructured study habits lead to inefficient cramming rather than consistent, spaced learning.
4. **Generic AI Tools:** Standard chatbots lack the context of a student's specific courses, deadlines, grade history, and career goals.

### ✨ The Solution Ecosystem
- **Centralized Academic Hub:** All courses, assignments, assessments, study logs, and group projects reside in a single database connected to Cloud Firestore.
- **Context-Driven AI Engines:** AI features analyze the student's actual active courses, upcoming deadlines, grade averages, and availability to offer personalized recommendations.
- **Proactive Risk Radar:** Evaluates academic performance in real time to alert students to falling grades or tight deadline clusters before they become critical.
- **Integrated Career Pipeline:** Translates academic progress into professional readiness through AI-generated career roadmaps and resume-to-portfolio parsing.

### 👥 Target Users
- **University & College Students** seeking structured academic organization.
- **Graduate Students** managing multi-faceted research projects, writing, and course loads.
- **Students Managing Multiple Courses & Deadlines** who need automated scheduling and risk evaluation.
- **Students Preparing for Careers & Portfolios** looking to align their degree coursework with real-world industry skills.

## 🤖 5. AI-Powered Features

Rather than operating as an isolated, generic chatbot window, the AI features in **CampusFlow AI** are deeply integrated into specific student workflows. The backend Express API handles requests to Google's Gemini models using `@google/genai` with strict JSON schema enforcement and system prompts.

### 🧠 AI Study Assistant
Simplifies complex academic topics step-by-step. Solves the problem of getting stuck on difficult textbook concepts or lecture slides without instructor availability.

### ✍️ AI Writing Assistant
Drafts articulate emails to faculty and administrative requests. Assists students in communicating professionally with academic personnel while maintaining the user's intended meaning.

### 💻 AI Code Assistant
Diagnoses syntax errors and runtime bugs while explaining the underlying CS principles. Helps programming students learn bug resolution clearly rather than only giving unexplained code.

### 🗓️ AI Personalized Study Plan Generation
Formulates structured study schedules tailored to course weightings and exam dates. Solves poor time management and unorganized study habits.

### ❓ AI MCQ Generation
Converts study notes into active practice tests. Solves passive reading habits by forcing active recall testing prior to exams.

### 🎴 AI Flashcard Generation
Produces digital flashcards instantly from syllabus content. Eliminates manual card creation time so students focus on active retrieval.

### 📄 AI Summary Generation
Synthesizes lengthy articles and lecture notes into key takeaways and formulas. Reduces review time during exam preparation.

### 📊 AI Academic Risk Analysis
Evaluates current course averages, deadline clusters, and study hours. Proactively alerts students to academic risks before grades decline.

### 🗺️ AI Career Roadmap
Generates sequential skill targets and project goals based on desired job titles. Helps students build job-ready portfolios alongside their degree.

### 💼 AI Resume & Portfolio Parser
Extracts structured profile data from unstructured resume text. Automatically updates portfolio skills and project history.

### 🏫 AI Campus Help Guidance
Answers university procedures and academic policy questions. Helps students navigate campus administration efficiently while clearly distinguishing between general guidance and official university policies.

### 👥 AI Project Manager
Decomposes group project briefs into team milestones and deliverables. Prevents unequal workload distribution and missed project milestones.

### ⚡ AI Automatic Scheduler
Distributes study blocks into available student time slots without overlapping. Prevents scheduling conflicts and cramming.

## 🏗️ 8. Application Architecture

### Workflow

```
1. Frontend (React + TypeScript)
       ↓
2. Authentication (Firebase Auth)
       ↓
3. Firestore (Cloud Firestore Database)
       ↓
4. Express API (Vercel Serverless Function)
       ↓
5. Gemini AI (@google/genai Server-Side)
```

### Architectural Details

1. **React + TypeScript Frontend:** Single-Page Application (SPA) providing a fast, interactive UI with Tailwind CSS styling and Motion animations.
2. **Vite Build System:** Optimized ES module bundle generation for fast development and production builds.
3. **Express Backend / API Layer:** Node.js Express serverless functions hosted on Vercel handling `/api/*` endpoints.
4. **Vercel Serverless API Deployment:** Runs API routes securely in edge/serverless container environments.
5. **Server-Side Gemini API Calls:** Powered by `@google/genai`. **`GEMINI_API_KEY` is kept strictly server-side and is never intentionally exposed to the client.**
6. **Firebase Authentication:** Handles user authentication via Email/Password and Google Sign-In.
7. **Cloud Firestore Database:** Provides real-time persistent NoSQL storage for student records, courses, tasks, study logs, and AI outputs.
8. **Environment Variables:** Used for secure server-side API keys and client Firebase initialization parameters.

## 🚀 10. Getting Started

Follow these instructions to set up and run CampusFlow AI locally on your machine.

### 📋 Prerequisites
- **Node.js** (v18.0.0 or higher)
- **npm** (v9.0.0 or higher)
- A **Firebase Project** with Cloud Firestore and Authentication enabled
- A **Google Gemini API Key**

### ⚙️ Local Setup Steps

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/farrrukhmobeen01-tech/app.ai.git
   cd app.ai
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory (refer to `.env.example`):
   ```env
   # Server-side Gemini API Key (Secret - Never prefix with VITE_)
   GEMINI_API_KEY=your_gemini_api_key_here

   # Client-side Firebase Configuration
   VITE_FIREBASE_API_KEY=your_firebase_api_key
   VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
   VITE_FIREBASE_PROJECT_ID=your_project_id
   VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
   VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
   VITE_FIREBASE_APP_ID=your_app_id
   ```

4. **Run Project (Development Server):**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000`.

5. **Build for Production:**
   ```bash
   npm run build
   ```

## 🔒 12. Security
